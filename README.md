# 한번에 얼굴 가리기

사진 여러 장의 얼굴을 자동으로 가리고, 한 장씩 확인한 뒤 보고서용 JPG·PNG로 저장하는 로컬 도구입니다. 사진은 외부에 업로드하지 않습니다.

## 실행

`한번에 얼굴 가리기 실행.cmd`를 두 번 클릭하세요. 브라우저가 자동으로 열립니다. 이미 실행 중이면 기존 앱에 연결됩니다.

- 현재 주소: **http://127.0.0.1:4174/**. 이전 1차 버전 주소(4173)와 다릅니다.
- 사용 중에는 최초 실행한 창을 열어두세요.
- 현재 컴퓨터에는 Node.js가 설치되어 있습니다. 다른 컴퓨터에서는 Node.js LTS 설치가 필요합니다.
- `index.html`을 직접 더블 클릭하는 방식은 지원하지 않습니다.
- 명령어로 실행하려면 `node server.cjs --open`을 사용합니다.

## 여러 사진 처리하기

1. **사진 여러 장 추가**를 누르거나 사진 여러 개를 작업 공간에 끌어다 놓습니다.
2. 자동으로 HEIC 변환과 얼굴 검출을 진행합니다. 처음에는 원본 위에 가릴 영역만 표시하며 아직 모자이크·블러를 적용하지 않습니다.
3. 왼쪽 사진 목록에서 한 장씩 선택합니다. **원본 비교**로 원본을 볼 수 있습니다.
4. 빠진 얼굴은 **영역 수정 → 영역 추가** 후 드래그합니다. 선택한 영역을 이동·크기 조절·삭제하거나 실행 취소할 수 있습니다.
5. 오른쪽에서 모양(사각형·타원형·정원), 효과(모자이크·블러), 강도, 얼굴 주변 범위를 조절합니다.
6. **설정 대상 → 선택한 영역**으로 해당 얼굴만 다르게 설정할 수 있습니다.
7. 영역과 저장 설정을 확인한 뒤 **가리기 실행**(변환 전용은 **변환 실행**)을 누릅니다. 실행 후 미리보기는 인코딩된 최종 이미지이며 용량도 실제 결과 기준입니다.
8. **이 사진 확인 완료**를 체크합니다. 다음 미확인 사진으로 이동합니다.
9. **확인한 사진 ZIP 저장** 또는 **이 사진 저장**을 누릅니다.

사진의 설정이나 영역을 변경하면 해당 사진의 확인 완료가 해제됩니다. ZIP에는 확인한 사진만 들어가며 순번을 붙여 같은 파일명끼리 충돌하지 않게 합니다. 원본은 덮어쓰지 않습니다.

**Delete 키:** 사진 목록에서 사진을 클릭한 뒤 누르면 해당 사진을 제외합니다. 편집 화면에서는 선택한 영역만 삭제합니다. 입력칸·선택 메뉴에서는 사진을 제외하지 않습니다. 사진 제외는 원본 파일 삭제가 아닙니다.

처음 불러온 사진뿐 아니라 목록에서 다시 선택한 사진도 항상 원본과 영역 테두리부터 표시합니다. 결과는 가리기 실행을 눌러 확인합니다.

**모바일:** 반응형 화면과 터치 영역 편집을 구현했습니다. 현재 `127.0.0.1` 주소는 서버를 실행한 컴퓨터에서만 사용할 수 있습니다. GitHub Pages에 배포하면 스마트폰 브라우저에서 배포 주소로 접속할 수 있습니다. 모바일 화면 크기 검증은 했지만 실제 iPhone·Android 기기 검증은 아직 하지 않았습니다. 모바일에서도 큰 사진을 많이 넣으면 메모리 제한이 생길 수 있습니다.

## 공통 설정과 개별 설정

- 사진을 넣기 전에 설정한 값은 새 사진의 기본값입니다.
- 사진이 있으면 오른쪽 설정은 현재 사진에 적용합니다.
- **현재 사진 설정을 전체 적용**으로 모양·효과·변환 방식·저장 설정을 일괄 적용하고 새 사진의 기본값도 갱신합니다.
- **개별 사진·영역 설정 유지**를 선택하면 따로 수정한 다른 사진과 영역의 설정을 유지합니다.
- **개별 설정까지 모두 바꾸기**를 선택하면 모든 사진과 영역을 공통 설정으로 바꿉니다. 영역의 위치와 크기는 유지됩니다.
- 수동으로 그린 영역은 그 크기를 그대로 사용합니다. 얼굴 주변 범위는 자동 검출 영역에 적용합니다.
- 정원은 영역의 짧은 변에 맞춰 그립니다. 얼굴 전체가 포함되는지 결과를 확인하세요.

## 형식 변환과 용량 줄이기

- **작업 방식 → 형식·용량 변환만**으로 얼굴을 가리지 않고 변환할 수 있습니다.
- 입력: JPG, PNG, WebP, HEIC, HEIF. 출력: JPG 또는 PNG.
- 보고서용: 최대 가로·세로 1,600px, JPG 품질 80%.
- 작은 용량: 최대 가로·세로 1,200px, JPG 품질 70%.
- 원본 크기 유지: 원본 해상도로 저장. JPG 품질은 별도 조절할 수 있습니다.
- 직접 설정: 최대 가로·세로와 JPG 품질 조절. 비율을 유지하며 작은 사진은 확대하지 않습니다.
- PNG는 투명 배경을 유지합니다. JPG의 투명 부분은 흰색으로 저장합니다.
- PNG 변환 결과는 HEIC나 JPG 원본보다 커질 수 있습니다. 목표 용량을 보장하지 않으며 실제 결과 용량을 표시합니다.
- HEIC의 대표 정지 이미지를 변환합니다. Live Photo의 동영상, 연속 프레임, HDR·색상 프로필·촬영 메타데이터 보존을 위한 도구는 아닙니다. 기종·파일에 따라 변환 실패할 수 있습니다.

## 로컬 처리·오프라인

모델과 변환 라이브러리를 앱에 포함했습니다. 로컬 실행 시 인터넷 없이 변환·검출·저장할 수 있습니다. GitHub 배포 주소는 첫 접속에 파일을 내려받으며 **오프라인 사용 준비 완료** 이후 캐시가 유지되는 동안 오프라인으로 열 수 있습니다.

사진은 브라우저 메모리에서만 처리합니다. 페이지를 새로고침하거나 닫으면 작업 목록이 사라집니다. 자동 검출은 사람의 신원을 식별하지 않으며 작은 얼굴·옆얼굴을 놓칠 수 있습니다.

처리는 순차적으로 진행합니다. 한 번에 최대 40장, 한 파일 30MB, 원본 합계 300MB, 한 장 2,400만 화소·한 변 16,000px까지 지원합니다. 변환 결과를 포함한 작업 데이터가 커지면 추가 처리가 제한됩니다. ZIP 결과는 합계 200MB 이하로 제한합니다. 처리 실패 사진은 다시 처리하거나 목록에서 제외할 수 있습니다.

## GitHub에 처음 배포하기

1. https://github.com/signup 에서 계정을 만들고 이메일 인증을 완료합니다.
2. https://github.com/new 에서 `face-cover`라는 **Public** 저장소를 만듭니다. README 추가를 켭니다.
3. 제공된 **github-pages-upload.zip**을 압축 해제합니다.
4. 저장소의 **Add file → Upload files**로 압축 해제한 **내용물**을 모두 업로드합니다. ZIP 자체나 바깥 폴더를 올리지 않습니다. `index.html`과 `vendor`가 저장소 루트에 있어야 합니다.
5. **Commit changes**로 저장합니다.
6. **Settings → Pages → Source → Deploy from a branch**를 선택합니다.
7. Branch **main**, 폴더 **/(root)**를 선택하고 **Save**를 누릅니다.
8. 배포 완료 후 **Visit site**로 엽니다. 주소는 보통 `https://내아이디.github.io/face-cover/` 형태입니다.

학생 사진이나 시험 사진은 저장소에 올리지 않습니다. 제공 ZIP에는 앱 파일과 사용 안내만 들어 있습니다.

공식 안내: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## 개발

- 정적 앱으로 별도 빌드 과정 없이 동작합니다. 시작 파일은 `studio.js`, 스타일은 `style.css`와 `studio.css`입니다.
- 실행 자산을 다시 받으려면 `download-assets.ps1`을 사용합니다(인터넷 필요).
- 수정 후 `sw.js`의 CACHE 버전을 올리세요. 새 버전 설치 후 페이지를 다시 열어야 새 화면이 반영됩니다.
- `npm test`로 좌표·크기 계산 검사를 실행합니다. 브라우저 검증은 Edge와 Playwright로 수행했습니다.
- 외부 라이브러리의 버전·라이선스·소스 위치는 `THIRD_PARTY_NOTICES.md`를 참고하세요.
